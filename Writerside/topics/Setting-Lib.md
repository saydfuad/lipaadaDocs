# Setting Lib

---
this section is where administrators can configure general library information, manage librarians, and organize sections.

---
## 1. General Settings
Linking Librarian to section will limit them to see books and borrowings of that section only.

## Steps 
1. Navigate to **Setting**
2. Click **General Setting**
3. Select section on drop down list e.g **Main Library** and **Teacher Library**.
4. Select librarian or select users **admin**, **muhammed** etc.
5. Click **Update Setting ** to save changes.

![](general setting2.PNG)

## Manage Sections
Organize library sections for books.
### How to add a section:
1. Go to the **Manage Sections** box.
2. Enter the Section Name.
3. Click **Add Section**
4. The new section appears in the list of Existing Sections, where it can be deleted.
